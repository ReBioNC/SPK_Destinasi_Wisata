01 / Pelatihan

Cara model dilatih

Pelatihan dijalankan offline dengan manage.py train_clusters, memakai implementasi NumPy pada train_clusters.py. Website hanya membaca hasilnya.

  1. Periksa artefak. Manifest preprocessing dicocokkan dengan sumber; artefak usang ditolak.
  2. Inisialisasi k-means++. Pusat pertama diambil acak, pusat berikutnya diberi peluang sebanding dengan kuadrat jaraknya ke pusat terdekat.
  3. Tetapkan cluster. Setiap destinasi masuk ke pusat dengan jarak Euclidean terdekat.
  4. Perbarui pusat. Pusat baru adalah rata-rata anggota cluster. Langkah 3–4 berulang sampai pusat berubah kurang dari 10−6 atau mencapai 100 iterasi.
  5. Ulangi 10 kali. Dari 10 inisialisasi (seed 42), disimpan hasil dengan inertia terkecil.
  6. Pilih k. Langkah di atas dijalankan untuk k = 2 sampai 6. Dipilih silhouette tertinggi pada k yang cluster terkecilnya minimal {{ model.minimum }} anggota (5% dari {{ model.rows_count }}).

04 / Silhouette

Cara menghitung silhouette

Silhouette membandingkan kedekatan satu destinasi dengan clusternya sendiri dan dengan cluster lain.

a(i)
Rata-rata jarak destinasi i ke anggota lain di clusternya. Makin kecil, makin rapat.
b(i)
Rata-rata jarak destinasi i ke anggota cluster lain yang terdekat. Makin besar, makin terpisah.
s(i)
Nilai −1 sampai 1. Mendekati 1 berarti tepat, mendekati 0 berarti di perbatasan, dan negatif berarti lebih dekat ke cluster lain.

s(i) = (b(i) − a(i)) / max(a(i), b(i))

Silhouette model = rata-rata s(i) seluruh {{ model.rows_count }} destinasi

Contoh: {{ model.example.nama }}

  1. Jarak ke pusat. {% for d in model.example.distances %}{{ d.label }} = {{ d.value }}{% if not forloop.last %}; {% endif %}{% endfor %}. Jarak terdekat menempatkannya di {{ model.example.own_label }}.
  2. a(i) = rata-rata jarak ke {{ model.example.own_others }} anggota lain di clusternya = {{ model.example.a }}.
  3. b(i) = rata-rata jarak ke {{ model.example.other_size }} anggota {{ model.example.other_label }} = {{ model.example.b }}.
  4. s(i) = ({{ model.example.b }} − {{ model.example.a }}) / {{ model.example.max }} = {{ model.example.gap }} / {{ model.example.max }} = {{ model.example.s }}.

07 / Batasan

Yang perlu diingat

  • Variasi terjelaskan hanya {{ model.metrics.explained }}%: dua segmen ini ringkasan kasar, terutama pembagian harga, bukan pengelompokan minat wisata yang rinci.
  • Segmen 2 kecil ({{ model.clusters.1.size }} destinasi) dan berisi destinasi dengan harga jauh di atas mayoritas.
  • K-Means sensitif terhadap skala dan pencilan, karena itu harga dibatasi P99 dan distandardisasi.
  • Label segmen tidak menyaring kandidat dan tidak mengubah skor TOPSIS.
  • Tidak ada data acuan, sehingga evaluasi ini internal dan bukan akurasi.
  • Rating dan harga adalah snapshot sumber. Rating Taman Hutan Raya Banten diisi median untuk pelatihan.
